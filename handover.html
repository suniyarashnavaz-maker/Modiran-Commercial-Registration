Meridian Corporate — Site Handover

Complete description of the website: technology, design system, pages, and a visual mockup of every major component.

توصیف کامل وب‌سایت: فناوری‌های به‌کاررفته، سیستم طراحی، فهرست صفحات و ماکاپ بصری از تمامی اجزای اصلی.

1. Site Description توصیف وب‌سایت

English EN

Programming languages & technology

  • HTML5 — page structure (12 static pages)
  • CSS3 — hand-written styles, CSS custom properties (design tokens), Flexbox & Grid, no framework
  • JavaScript (ES6, vanilla) — navigation, trilingual i18n engine, dynamic service pages, file-upload UI, forms, order tracking, admin panel. No frameworks, no build step, no dependencies.
  • Backend: Node.js server (server.mjs) — serves the pages and a JSON API for forms, real file uploads, order tracking, user accounts and the admin panel. Zero external dependencies.
  • Storage: server-side data.json (orders, messages, articles, users, settings) + uploads/ folder for customer documents; language preference remembered per browser
  • Fonts: Inter (Latin) + Vazirmatn (Persian/Kurdian) via Google Fonts
  • Testing: automated smoke test (plain Node.js, no dependencies) — 30 endpoint checks, all passing

Color scheme

  • Navy blue #1d3357 (deep #0d1930) — navbar, headers, primary buttons, footer
  • Gray #f5f6f8 → #5b6675 — backgrounds, borders, secondary text
  • Light wood #c8a878 (pale #faf6ee) — accents, highlights, active states, CTA buttons

Layout style

  • Responsive, mobile-first; centered 1200px container; hamburger menu under 900px
  • Sticky top bar (phone + language switcher) above a sticky navy navbar with 7 dropdown menus
  • Card-based sections: service cards, pricing tiers, blog cards, stat cards
  • Full RTL/LTR support — layout, arrows, carets and form alignment flip automatically for Persian & Kurdish
  • Trilingual (EN / FA / KU) with instant in-page switching and per-browser memory

Pages (12 files, 34 addressable pages)

  • Home · Service (×22 variants via ?id=) · Packages · Blog · About · Contact · Terms · Track Order · Login/Sign Up · Upload Documents · Consultation · Admin Panel

Key features

  • Drag-&drop document upload with per-file progress and validation — files are stored on the server
  • Consultation booking form with service selection
  • Order tracking with visual status timeline (real order numbers, e.g. MC-2026-00128)
  • Customer accounts: sign up / log in (passwords hashed, session cookies)
  • Admin panel: dashboard stats, orders, trilingual service management, articles, messages, users, settings — all changes persist on the server (login with password admin, changeable via the ADMIN_PASSWORD environment variable)

فارسی FA

زبان‌ها و فناوری‌های برنامه‌نویسی

  • HTML5 — ساختار صفحات (۱۲ صفحهٔ استاتیک)
  • CSS3 — استایل‌نویسی دستی با متغیرهای CSS (Design Tokens)، Flexbox و Grid، بدون هیچ فریم‌ورکی
  • جاوااسکریپت (ES6، وانیلا) — منو، موتور سه‌زبانی، صفحات پویای خدمات، رابط آپلود مدارک، فرم‌ها، پیگیری سفارش و پنل مدیریت. بدون فریم‌ورک، بدون مرحلهٔ Build و بدون وابستگی خارجی.
  • بک‌اند: سرور Node.js (server.mjs) — ارائهٔ صفحات + API JSON برای فرم‌ها، آپلود واقعی مدارک، پیگیری سفارش، حساب کاربری و پنل مدیریت. بدون هیچ وابستگی خارجی.
  • ذخیره‌سازی: روی سرور — فایل data.json (سفارش‌ها، پیام‌ها، مقالات، کاربران و تنظیمات) و پوشهٔ uploads/ برای مدارک؛ زبان انتخابی در مرورگر به‌یاد سپرده می‌شود
  • فونت‌ها: Inter (لاتین) + وزیرمتن (فارسی/کردی) از Google Fonts
  • تست: تست خودکار دود (Node.js خالص، بدون وابستگی) — ۳۰ بررسی، همهٔ موفق

پالت رنگی

  • سرمه‌ای #1d3357 (تیره #0d1930) — نوار ناوبری، سربرگ‌ها، دکمه‌های اصلی و فوتر
  • خاکستری #f5f6f8 → #5b6675 — پس‌زمینه‌ها، حاشیه‌ها و متن‌های فرعی
  • چوب روشن #c8a878 (کمرنگ #faf6ee) — تأکیدها، حالت‌های فعال و دکمه‌های دعوت‌به‌عمل

سبک چیدمان

  • ریسپانسیو و موبایل‌محور؛ کانتینر مرکزی ۱۲۰۰ پیکسلی؛ منوی همبرگری زیر ۹۰۰ پیکسل
  • نوار بالایی چسبان (تلفن + جابه‌جای زبان) روی نوار ناوبری سرمه‌ای با ۷ منوی کشویی
  • بخش‌های کارت‌محور: کارت خدمات، پلن‌های قیمت، کارت بلاگ و کارت آمار
  • پشتیبانی کامل راست‌چین/چپ‌چین — چیدمان، فلش‌ها و فرم‌ها برای فارسی و کردی به‌صورت خودکار معکوس می‌شوند
  • سه‌زبانه (انگلیسی / فارسی / کردی) با جابه‌جایی فوری در همان صفحه و به‌یادسپاری زبان در هر مرورگر

صفحات (۱۲ فایل، ۳۴ صفحهٔ قابل‌دسترسی)

  • صفحهٔ اصلی · خدمات (۲۲ نسخه با ?id=) · پکیج‌ها · بلاگ · درباره ما · تماس · قوانین · پیگیری سفارش · ورود/ثبت‌نام · آپلود مدارک · رزرو مشاوره · پنل مدیریت

امکانات کلیدی

  • آپلود مدارک با درگ‌اند‌دراپ، نوار پیشرفت و اعتبارسنجی هر فایل — فایل‌ها روی سرور ذخیره می‌شوند
  • فرم رزرو مشاوره با انتخاب نوع خدمت
  • پیگیری سفارش با تایم‌لاین بصری وضعیت (شمارهٔ واقعی سفارش، مثلاً MC-2026-00128)
  • حساب کاربری: ثبت‌نام / ورود (رمزها هش‌شده، نشست با کوکی)
  • پنل مدیریت: آمار داشبورد، سفارش‌ها، مدیریت سه‌زبان خدمات، مقالات، پیام‌ها، کاربران و تنظیمات — همهٔ تغییرات روی سرور ماندگار است (ورود با رمز admin؛ قابل تغییر از طریق متغیر محیطی ADMIN_PASSWORD)
